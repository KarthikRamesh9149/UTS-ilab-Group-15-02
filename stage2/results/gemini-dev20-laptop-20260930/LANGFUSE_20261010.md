## Logged information

Langfuse contains setup, agent, graph, tool, generation, verifier and cleanup
observations: identities, timing, status, token usage, known costs and outcome
metadata. Full model exchanges, tool arguments/output, trajectories and original
evidence remain in the existing private log folder. No provider API key or
model gateway is configured in the Langfuse stack; its AI agent is disabled.

The importer uses bounded 200-observation batches, stable span IDs, private
acknowledgement receipts and full observation-ID readback. Interrupted imports
can resume. To restore a reset Langfuse database, use `--reexport`; this sends
the same identities. An HTTP acknowledgement alone is not verification.

## Local configuration

Private configuration, login instructions, import receipts and Docker startup
logs are outside Git:

```text
F:/Capstone/.runtime/langfuse-local-20261010/
  compose.yml          # pinned running image digests
  .env                 # generated private service secrets
  credentials.json     # local project API keys and login
  login.txt            # dashboard email/password
  receipts/            # per-batch acknowledgements
  docker-startup.log
  backfill.log
  readback.json
  usage-audit.json
```

Only the web UI (3300) and blob endpoint (3390) are published, both on
`127.0.0.1`. Databases and worker remain inside the Docker network. Telemetry
is disabled; Docker logs rotate at 10 MB with three files per service.

The setup follows the official [Docker Compose deployment guide](https://langfuse.com/self-hosting/deployment/docker-compose)
and [headless initialization](https://langfuse.com/self-hosting/administration/headless-initialization).
The upstream compose source is pinned to
`eecc7d023b9aa351bb96b3ddd22cf6761a842dd9`; downloaded images are pinned by digest.

Start or stop this stack without deleting its data:

```powershell
docker compose -p uts-langfuse -f F:/Capstone/.runtime/langfuse-local-20261010/compose.yml --env-file F:/Capstone/.runtime/langfuse-local-20261010/.env up -d
docker compose -p uts-langfuse -f F:/Capstone/.runtime/langfuse-local-20261010/compose.yml --env-file F:/Capstone/.runtime/langfuse-local-20261010/.env stop
```

From the repository root, repeat a metadata readback with Python:

```powershell
python stage2/gemini_langfuse.py --source F:/Capstone/.runtime/gemini-dev20-laptop-20260930/traces --results stage2/results/gemini-dev20-laptop-20260930 --credentials F:/Capstone/.runtime/langfuse-local-20261010/credentials.json --state F:/Capstone/.runtime/langfuse-local-20261010/receipts --report F:/Capstone/.runtime/langfuse-local-20261010/readback.json --readback-only
```

Local Langfuse uses about 2.8 GiB while idle on this Docker instance. Future
task execution must account for this alongside official task memory limits;
