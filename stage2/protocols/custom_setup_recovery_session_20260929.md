# Recovery-only locked prerequisite session

`no_cutoff_recovery_session.open_session(stream)` joins the existing actual
recovery handoff and C0-NC host/library readers. This is local implementation,
not a native session invocation, qualification, registration or paid admission.
It has no CLI, caller root, factory, authentication callback, saved witness or
receipt entry. The future pinned SSH service must call it and consume its scope
on the same native process, main thread and async task.

The reader checks its own fixed recovery root/interpreter, full canonical
protected ancestry, exact private original qualification, raw manifest and all
current source bytes and loaded origins. It then calls the real handoff reader:
the actual fresh original completed audit and strict authentication of the same
retained off-server archive finish BEFORE any outer ancestor lock. No old
reporter, collector, handoff or source tree is changed or impersonated.

The lock sequence exactly extends the unchanged original final dispatcher's
chain with all three original-final locks. Every earlier matrix/scored/gateway
lock is retained. The new root's matrix lock is held here; its scored/gateway
locks remain owned by the future per-attempt lifecycle. All lock files must
already exist under protected canonical ancestry, with owner/group, ACL,
regular/single-link and exact0600 checks. The future exclusive installer must
create the new root's matrix lock. This component never creates, writes,
replaces or chmods lock files, including in historical roots. Nonblocking
contention fails; no wait loop, forced unlock or native signal exists.

Acquisition binds actual file descriptors and identities. Rechecks verify the
same paths/descriptors and challenge a second open-file description, which must
still conflict. A lost lock, replaced inode, changed permission/ACL, closed
descriptor or missing file refuses. Directory identity/protection is retained;
ordinary directory mtime/link-count changes from future exclusive producer
writes are not evidence drift. Native filesystem/flock compatibility remains
unexercised until actual Linux qualification.

Under those locks, the actual runtime reader checks the fresh witness, original
and recovery source/private bytes, current libraries/constructors, whole host,
Python, dataset, all official configurations and selected images. The returned
records must agree on the exact original qualification/runtime, three-cell plan,
current source union and actual predecessor. Final source/private identities
and loaded origins are reread after runtime's final actual historical/library/
dataset reads. No later service/image observation bypasses those final reads.

The handle cannot be copied, saved, forged, nested or transferred between
processes, threads or async tasks. A failed check invalidates both the session
and handoff witness permanently; restoring bytes cannot revive them. Normal
exit performs another actual under-lock recheck. Both handles are invalidated
before any lock is released, including caller failure, cancellation, partial
acquisition and entry failures. Invalidation alone does not release locks while
the context remains open. Recheck never calls a collector, transfers an archive
or recursively acquires the ancestor chain.

`describe` returns a deep-copied, non-admitting view, not fresh host evidence.
The component deliberately has no qualification verification, registration,
dispatch permit, replay policy bypass, provider call or persistent writer.
Saved qualification JSON cannot be promoted to live admission here. Real pinned
SSH/service wiring, source-bound image/producer verification, isolated native
regressions and six genuine fake-model cases, durable setup-observer/scored
integration, one-shot sequential dispatch and separate completed audit/ONE
backup/export remain required. A fresh context is not authority to repeat a
started key. Original89 and recovery3 remain separate; no agent/model/tool,
setup command, official allowance or financial/request ceiling changes.

Tests use actual temporary private files, local pipes and competing flock
descriptors with mocked native service/host/library/audit observations. They do
not read the retained original archive, create a native root, run Docker or
contact a provider. Present-day library parity remains distinct from historical
installed-byte attestation; the original archive contains no virtualenv.
