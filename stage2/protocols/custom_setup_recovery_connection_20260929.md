# Recovery-only pinned inspection connection

This is a locally implemented **prerequisite inspection** operation, not a
native invocation, installation, qualification, registration or paid attempt.
It preserves the fixed recovery3 plan and original89 outcomes. No archived35,
old matched-repeat transport, handoff, host/library/session or scored source is
edited. A future exclusive installer must first verify actual new-root absence
and install the full committed source/input set and existing private locks.

The fixed Mac `inspect_native(full_commit)` requires actual committed sources,
HEAD/fetched main, original private/public metadata and the retained original
backup inventory before SSH. It preserves the exact existing SSH destination,
identity, known-host file, strict host-key checking and noninteractive options.
Only the original interpreter tail is replaced. No credentials are sent to the
native service. `handoff.send` always performs its actual fresh original audit
and strict same-retained-archive capture; no saved receipt substitutes.

The committed stdlib bootstrap checks every inherited/current source and the
exact private original qualification before project imports. Its inventory is
derived from actual bound qualification and policy bytes, not an incomplete
caller list. Canonical full ancestry, owner/group/ACL, single links, raw hashes,
file identities, exact credential-free environment and absent bytecode prefix
are checked before/after imports. Imports cannot write, create subprocesses or
connect; caught socket-construction capability probes are denied before any
socket exists. Other refused effects latch failure. Credential reads and
environment mutation remain forbidden afterward. Actual loaded project origins
are checked. This is defence in depth, not an OS sandbox.

The SSH relay starts a detached systemd Type=exec service with Restart=no,
null standard input and an exclusively created private log. There is no
--pipe/--scope/--wait or service runtime ceiling. A private short Unix socket
connects relay and service. Both inspect Linux peer credentials and actual
PID/start-tick/executable/cwd/owner identity; the relay also checks the actual
unit MainPID and invocation identity twice. Local peer checks complement the
pinned SSH route, not proof of a network peer or off-server archive by themselves.

The service opens the real recovery session inside its own main-thread async
task. Actual handoff authentication/audits finish before all34 ancestor locks;
actual host/library inspection and final rereads remain inside that scope.
Neither relay nor Mac owns or transfers a session handle. Complete transfer
and final commitment are mandatory. The actual live handoff's operator revision
must equal the committed revision in the detached operation's intent; a saved
document or a later checkout change cannot relabel the inspected operation.
Once delivered, SSH acknowledgement loss
cannot stop the detached operation. Transport/parser windows do not constrain
benchmark tasks, model requests or future service execution.

The Mac and native operation each use one fixed exclusive private state folder.
Existing/partial folders and an exclusive service-start record prohibit silent
repetition or restart. Failures retain only fixed status/identity metadata,
never raw stderr, exception messages, payloads or model exchanges. The archive
is streamed without being written/extracted natively or recreated on the Mac.
Only the exact exclusively owned ephemeral socket may be removed; replacements
and all durable evidence stay untouched. Only an owned Mac SSH client can be
terminated on transport failure. No native signal, stop, resume or retry exists.

Intermediate prerequisites are explicitly non-admitting. The service writes
its successful result and acknowledgement only **after normal session exit and
its final recheck**, when both handles are invalid. Final source/private/input
and operation-evidence rereads precede completion. The Mac verifies exact
operation/process/archive/capture identities, successful SSH exit and EOF, then
rereads current sources and retained operator state. An inspection receipt
cannot be reused to qualify, register, dispatch or repeat a started task.

Actual Linux/systemd/socket/runtime compatibility is unexercised. The real
qualification/paid service branches, scoped scored admission, durable setup
observation integration, source-bound image build/native qualifier with six
genuine fake-model cases, sequential dispatcher and separate completed audit,
ONE backup and export remain required before paid recovery. None is supplied
or authorised by this inspection-only component or its local tests.
