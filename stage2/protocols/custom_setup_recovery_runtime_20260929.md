# Recovery-only current host and library identity

This component implements local recovery readers, not native installation,
qualification, registration, admission or a new benchmark outcome. The original
89 results, archived35 reporter, retained archive and three-cell recovery plan
are unchanged. No historical source inventory or installed-byte claim expands.

`no_cutoff_recovery_runtime.inspect(witness)` requires the actual in-memory
recovery original-evidence witness on its owning process, main thread and async
task. The future trusted session must authenticate the fresh original audit and
the same retained off-server archive **before** acquiring the full ancestor
lock chain; it must hold those locks for this reader and invalidate its witness
before exit. This component acquires no locks and invokes no collector, archive
transfer, container creation, build, agent lifecycle, tool or model. A saved
description or matching library report is not an admission substitute.

The reader binds the exact original qualification/runtime, current recovery
source union, manifest, Python archive, dependency versions and entire stable
host identity. Actual canonical dataset files are hashed without interpreting
task solutions or model exchanges. All89 official task configurations are
checked; the separate identity retains only the fixed63-65 task/image/resource
and deadline bindings. Dataset files also require actual canonical protected
ancestry, ownership/group/ACL/link checks and unchanged raw bytes. Actual Docker metadata must match the three existing
task images and original gateway/guard images. The new recovery gateway image
still requires its future real build, inspection, qualification and producer
bindings. No image is pulled, created, installed or repaired here.

`no_cutoff_recovery_libraries.py` is a stdlib-only producer sent through stdin to
each fixed installation's own isolated `-I -B` interpreter. Full committed
source binding and pre-import source/origin protection must be supplied by the
future trusted service. Each child independently checks its actual bound
sources/private qualification, exact credential-free environment, canonical
ownership/group/ACL/link/mode protection and an absent bytecode prefix. The
original protected-root group-write compatibility does not extend to the new
recovery tree or private inputs, which require0600. Files are opened no-follow
and nonblocking with before/after descriptor/path/ancestry identity checks.

Every current site-packages file, including unrecorded files and distribution
RECORD bytes, is hashed before and after construction. Only bytecode caches are
excluded. Symlinks, special files, unsafe ancestry, duplicate/unpinned package
versions and loaded project/library origins outside the actual bound tree
refuse. Seed installers are version/byte compared, not silently omitted.
Current original-vs-recovery Python versions, installed bytes, distributions
and actual C0-NC constructor controls must match. The three unchanged helper
imports missing from original211 are separately CURRENT-bound; they are not
retroactive original qualification or historical installed-byte attestation.

Construction uses the original C0-NC factory, C0 parent, text-only model class,
sampling/provider/reasoning settings and deadline wrapper with a synthetic key.
It never calls setup/run, prepares a task, creates a graph or executes tools.
The7200-second constructor fixture checks timeout forwarding, not a new official
deadline. Audit hooks refuse credential reads, writes, subprocess creation and
network effects. Libraries may catch blocked socket-construction capability
probes; no socket is created and only the refusal count is returned. Other
credential/environment/write/process/connection violations latch refusal even
if a library catches them. This is defence in depth, not an OS sandbox.

After the final actual host/image/service observations, the reader rereads
actual source/private inputs, both installed library inventories, Python and
dataset bytes; the handoff reader retains its original/private/public/producer
inventories, genuine absences and all182 historical-result rereads. No saved
snapshot or caller-selected root/factory/transport can replace these reads.
Any failed inspection/recheck invalidates the witness; restored bytes do not
revive it. Recheck performs actual reads again, not a saved-record acceptance.

The original backup excluded the virtual environment. Present-day parity cannot
prove which third-party bytes were installed during the old paid run. External
scripts, stdlib, OS and task-container installation are outside the library
inventory and retain their separate runtime/native qualification requirements.
Returned metadata states these limitations and remains paid_launch_ready:false.

Local tests use real temporary protected files, actual constructor imports and
mocked native host, Docker, service, subprocess results and witness observations.
They are not genuine Linux qualification or paid recovery results. The actual
live locked session, pinned SSH/service wiring, durable observer integration,
scoped scored admission, genuine regressions/six fake-model lifecycle cases,
sequential dispatcher and separate audit/ONE backup/export remain required.
No recovery installation or attempt is authorised by this component alone.
