# Recovery-specific original-evidence handoff

This implements a new recovery capture and live evidence reader without changing
the original archived 35-file reporter, any original result or the retained
archive. The recovery plan, original C0-NC controls and separate denominator
three are unchanged. This is not a native service, qualified host or paid scope.

## Actual operator route

The fixed Mac entry `no_cutoff_recovery_predecessor.capture(full_commit)`
requires current HEAD and fetched origin/main, exact committed recovery sources,
original qualification/manifest copies, already committed public outputs, the
exact completed private export/backup inventories and retained earlier failed
backup. New recovery source bindings are kept separate from the archived
reporter's old revision. They are current controls, not historical additions.

Capture calls the unchanged internal exporter verification operation. That
operation always performs the actual fresh original native audit, compares all
fields except collection time, requires a non-older observation and strictly
reads the SAME existing archive. Public return flags, saved diagnosis, supplied
snapshots or caller-selected archives cannot replace it. The stable audit,
snapshot, archive, backup-record and all 89 result hashes must match the fixed
recovery policy. No writer, new export, archive copy or extraction is provided.

`no_cutoff_recovery_handoff.send(pipe)` captures afresh, preserves the exact
snapshot/backup UTF-8 bytes and Python numeric identities, streams the one
existing compressed archive and rereads actual local source/input/export/private
state/archive bytes before its final commitment. Mutation withholds commitment.
It does not create another archive pathname or automatically repeat an operation.

## Actual native evidence route

`authenticate(pipe)` accepts only the fixed separate recovery deployment, its
isolated no-bytecode interpreter, main thread and current async task. Actual
private ancestry, ownership, groups, ACL absence, links, before/after identities,
source bytes and loaded origins are checked. The original frozen-root narrow
permission exception remains confined to that root; recovery has no equivalent
public group-write exception. Actual original service inactivity and final
trusted manager/procfs completion are checked before authentication and again
before final evidence rereads. Persistent stop markers refuse the route.

Only the recovery envelope is accepted, never a Terminus/OpenHands identity.
The reader compares its actual current source/input/public bytes to the bound
operator capture; independently checks original native anchors and actual
archived reporter/state files; strictly verifies archive members, hashes,
inventories, genuine absences and checksum; and requires exact final commitment
and EOF. It never extracts or writes private archive content.

It then invokes the actual original isolated-interpreter reporting bootstrap
with the exact credential-free environment. The fresh native audit must match
the pinned original evidence apart from collection time and must not predate
the retained snapshot. The native audit takes its own full ancestor locks, so
authentication MUST precede the future recovery session's full ancestor locks.
Final checks reread real sources, private inputs, actual reporting producer
files, supporting inventories/absences and all 182 historical result hashes.

The returned witness is in-memory and nonserialisable, bound to its process,
main thread and async task. `describe` returns a deep-copied non-admitting view.
A failed recheck or ownership violation invalidates the witness permanently.
`invalidate` lets the future owning session revoke it before releasing locks.
Under-lock `recheck` performs only real byte/inventory/absence rereads; it never
calls a collector, transfers an archive or recursively acquires ancestor locks.
A fresh witness is not permission to replay a started task.

The unchanged low-level framing helper is reused; its old baseline archive
verifier and old baseline handoff/capture are NOT invoked. A pipe/socket type,
valid JSON or successful local fixture is not authenticated network identity,
off-server location proof, historical installed-byte attestation or a full
runtime restore.

## Remaining native work and evidence boundary

The trusted pinned SSH relay/service, actual new-root absence/pre-import install
checks, C0-NC runtime/library/image checks, full locked session, genuine isolated
qualification, scoped scored/observer durable result integration, sequential
dispatcher and separate completed reporting/one-backup/export remain required.
No native recovery operation, actual handoff, registration or paid attempt is
performed by this implementation checkpoint. Local tests use synthetic private
files/tar bytes and pipes with mocked native service/audit observations, never
the real original archive or paid provider.
